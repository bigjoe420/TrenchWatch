three calls, one API key

The smallest honest Helius demo: a plain JSON-RPC call, and two DAS (Digital Asset Standard) reads — the same surface TrenchWatch itself uses. No framework, no SDK, fetch only.

checking for a key…

Key comes from .env.local (VITE_HELIUS_API_KEY), never from source. Every failure state is shown as-is — HTTP status, JSON-RPC error, or timeout — instead of being swallowed.
