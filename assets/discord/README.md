# Discord assets

Server icon + custom emoji set for the TrenchWatch alerts server
(invite: https://discord.gg/SNjAp6FQB).

- `trenchwatch-server-icon.png` (512x512) — upload at
  Server Settings -> Upload Icon.
- `emoji-*.png` (128x128) — upload at Server Settings -> Emoji.
  Suggested names: `trenchwatch`, `helius`, `graduated`, `critical`,
  `warn`, `radar`, `receipt`, `pump`.
- `generate_emojis.py` regenerates every emoji from the in-app palette;
  run from the repo root: `python assets/discord/generate_emojis.py`.
